# Creative Designer & Video Editor Portfolio — Website Design Prompt

Create a premium, modern, highly visual portfolio website for:

**Ahmed Mahmoud**
**Graphic Designer & Video Editor**

The website must be inspired by the uploaded reference image `hero-imag.jpeg`.

The reference image represents the client's visual identity:
- Creative professional
- Graphic design
- Video editing
- Adobe-style creative tools
- Cinematic production
- Neon colors
- Dark studio environment
- Professional but energetic personality
- Strong visual storytelling

Do NOT simply reproduce the image as a website.
Use its visual language and transform it into a polished professional portfolio.

---

# 1. Overall Design Direction

Build a **cinematic creative portfolio** with a premium digital-studio feeling.

The design should combine:

- Dark creative studio aesthetic
- Neon cyan
- Electric blue
- Purple
- Magenta
- Orange/yellow accents
- Deep black/navy backgrounds
- Glassmorphism used carefully
- Soft glowing borders
- Cinematic lighting
- Subtle gradients
- Large typography
- Smooth animations
- Creative transitions
- Editorial portfolio layouts

The website should feel like:

> Adobe Creative Cloud × futuristic creative studio × cinematic portfolio

Avoid making it look like a generic SaaS website.

Avoid excessive glassmorphism.

Avoid excessive rounded cards.

Avoid overly complicated animations.

The portfolio itself should remain the main focus.

# 4. Dark Mode

Dark mode is the primary visual experience.

Dark mode colors:

Background:
#050509 / deep black

Secondary background:
#0B0D14

Accent colors:
- Cyan
- Electric Blue
- Purple
- Magenta
- Orange

Use subtle gradients such as:

cyan → blue → purple

and

purple → magenta → orange

Do not use gradients everywhere.

Use them strategically for:

- Buttons
- Text highlights
- Borders
- Decorative elements
- Hover effects
- Section transitions

# 5. Light Mode

Create a proper light mode, NOT simply an inverted dark mode.

Light mode should use:

- White
- Soft gray
- Very light blue
- Subtle purple
- Dark text

Maintain the same creative identity.

The neon colors should become accent colors rather than dominating the entire interface.

The website should remain professional and readable in light mode.

# 6. Language Support

The entire website must support:

**English + Arabic**

Arabic must be a real RTL layout.

When Arabic is selected:

- Navigation becomes RTL
- Text alignment changes appropriately
- Cards and layouts adapt naturally
- Icons that imply direction should flip when necessary
- Animations should feel natural in RTL

Do NOT simply translate text while keeping the English layout.

The layout itself must support RTL properly.

Example:

Graphic Designer & Video Editor

مصمم جرافيك ومونتير فيديو

# 18. RESPONSIVE DESIGN

The website MUST be fully responsive.

Desktop:
1440px+

Laptop:
1024–1439px

Tablet:
768–1023px

Mobile:
320–767px

Do not simply shrink the desktop design.

Create intentional layouts for each breakpoint.

Mobile Hero:

Text first.

Client image second.

Mobile portfolio:

2-column grid where appropriate.

Videos:

1-column layout if necessary.

Navigation:

Hamburger menu.

Floating WhatsApp button must not cover important content.

Ensure:

- No horizontal scrolling
- No overlapping text
- No cropped buttons
- No broken images
- No overflowing animations

# 23. Performance

This is a portfolio website, so performance is critical.

Implement:

- Lazy loading images
- Responsive image sizes
- WebP/AVIF where possible
- Lazy loading videos
- Optimized thumbnails
- Avoid loading large videos before needed
- Avoid unnecessary JavaScript
- Avoid excessive animation libraries
- Respect `prefers-reduced-motion`

The Hero image should be optimized without visibly reducing quality.

The website should feel like the **online studio of a creative professional**, not a standard developer portfolio.

Use the uploaded image as the visual identity anchor.

The reference image's visual language should influence:

- Colors
- Lighting
- Typography
- Motion
- Portfolio presentation
- Decorative elements

But the final website must be cleaner and more professional than the image itself.

Think:

"Cinematic creative studio website"

"Personal landing page."
